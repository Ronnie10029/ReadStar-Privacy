ReadStar All Apps Analytics

A personal administration tool operated by Ronnie Reyes to collect Apple App Store Connect analytics for the operator's apps and synchronize the reports to the operator's Google Drive.

The tool automatically discovers apps accessible to the operator's existing Apple API key. It runs in a private GitHub repository using GitHub Actions. It is intended for the app owner, rather than users of the children's ReadStar reading app.

Google Drive access

The tool requests Google's drive.file permission. It can manage only files it creates or files explicitly made available to it. It uses this access to create report folders, upload report files, check file names and checksums, and repair changed uploads.

Google OAuth credentials are stored as encrypted GitHub Actions secrets. Report contents are stored in the operator's Drive folder, with temporary copies during processing. No analytics reports or credentials are published on this website.
