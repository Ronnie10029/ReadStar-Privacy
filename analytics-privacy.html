ReadStar All Apps Analytics

Analytics tool privacy policy

Effective October 20, 2026

This policy describes ReadStar All Apps Analytics, a personal administration tool operated by Ronnie Reyes. The children's ReadStar reading app has its own privacy policy.

Information accessed and purpose

The tool retrieves analytics reports made available by Apple App Store Connect for the operator's apps. It stores these reports in the operator's Google Drive. Google Drive access is limited to the drive.file scope: files the tool creates or files explicitly made available to the tool.

To synchronize reports, the tool accesses folder and file identifiers, names, file types, checksums, and write capabilities for its destination. It uploads report contents, compares checksums, and updates changed report files. It does not request access to the account's entire Drive.

Use and sharing

Google user data is used only to provide this report-storage and synchronization function. It is not sold, used for advertising, or used to train generalized artificial-intelligence or machine-learning models. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Google processes files stored in Drive. GitHub processes credentials and temporary report files when the private GitHub Actions workflow runs. The account owner and anyone the owner authorizes to access the destination or repository may have access consistent with those permissions. Reports and credentials are not published in this public documentation repository.

Storage and safeguards

OAuth client credentials and refresh tokens are stored in encrypted GitHub Actions secrets. Local setup copies are kept outside the source repository with restricted file permissions. The workflow creates the Apple key in a temporary file and removes temporary credentials and reports during cleanup. Report files remain in Google Drive until the account owner deletes them. Workflow logs record processing status; credential values and API response bodies are excluded.

Control, retention, and deletion

The account owner can delete report files in Drive, remove GitHub Actions secrets, and revoke the tool's Google authorization through Google Account connections. Revoking authorization stops future Drive access; it does not delete files already stored. Local copies and existing Drive files must be deleted separately when no longer wanted.

Contact and updates

Questions about this tool or its handling of data can be sent to Ronnie.Reyes@live.com. Changes to this disclosure will be reflected by updating its effective date.
